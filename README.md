# CanteenIQ | The Kinetic Hearth

![Cinematic Preview](file:///C:/Users/mayan/.gemini/antigravity/brain/f0de2ef3-8864-4be1-a5bf-b9f9f59fad51/hero_restored_to_kinetic_flow_final_1776606383306.webp)

**CanteenIQ** is a premium, cinematic web experience for a smart canteen ordering platform. Designed with "The Kinetic Hearth" aesthetic, it transforms the simple act of food ordering into a high-fidelity, scroll-driven narrative.

---

## 🌟 The Experience

### 1. Cinematic Scroll Hero
A 600vh scroll-hijacked section featuring a 240-frame high-speed photography sequence of floating ramen noodles. 
*   **Performance**: Renders via a hardware-accelerated `<canvas>` for 60fps scrubbing.
*   **Atmosphere**: CSS-only steam particles and a vertical ember progress bar.
*   **Storybeats**: Multi-stage text overlays that reveal the project vision as the user scrubs through the animation.

### 2. The Kinetic Flow
A 250vh sticky section that visualizes the "Digital-to-Physical" handoff.
*   **Staggered Reveal**: Sequential activation of process steps (Order → Token → Pick Up).
*   **Visual Logic**: Ghosted-to-Active state transitions with amber pulse-rings and shimmer-gradient connector lines.

### 3. Design System: The Kinetic Hearth
Strict adherence to a custom design language:
*   **Palette**: Obsidian Void (#000000) background with Amber Ember (#ffa84f) accents.
*   **Glassmorphism**: Tonal layering with 20px backdrop blur and ghost borders.
*   **Typography**: Premium pairing of *Plus Jakarta Sans* (Heading) and *Manrope* (Body).

---

## 🛠 Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+).
- **Styles**: Tailwind CSS (Utility classes) & Custom Vanilla CSS (Design tokens).
- **Animation**: `requestAnimationFrame` (RAF) logic for high-performance scroll interpolation.
- **Rendering**: Canvas API for sequential frame management.

## 🚀 Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/May-Jo/canteeniq.git
    ```
2.  Navigate to the project root.
3.  Ensure the `noodles animation/` folder is present for the hero sequence to load.
4.  Open `stitch_canteeniq_interactive_3d_homepage/code.html` in any modern browser.
